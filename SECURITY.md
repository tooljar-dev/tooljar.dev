# Security

Please report security problems privately: https://github.com/tooljar-dev/tooljar.dev/security/advisories/new, or by email to saba@tooljar.dev.

The site keeps no request logs and stores no IP addresses. Each tool has its own repository and its own security page: [ip](https://github.com/tooljar-dev/ip), [email](https://github.com/tooljar-dev/email).
